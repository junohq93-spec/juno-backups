Juno Backups

Privacy policy

Last updated: 7 November 2026

Juno Backups is a personal utility operated by the owner of the junohq93-spec GitHub account. It is being configured for the owner's own use; it is not a service offered to other users.

Google data and purpose

The utility requests Google Drive access to create backup folders, upload encrypted backup archives, verify file identifiers, names, sizes and integrity metadata, and manage retention. Drive file contents may be downloaded to verify or restore backups. Drive storage usage may be checked to avoid exhausting the owner's storage. It does not request Gmail, Calendar, Contacts, Docs or Sheets access.

Storage and security

Backup archives are encrypted before upload and stored in the owner's Google Drive. Google OAuth credentials are stored on the owner's server with restricted file permissions. Temporary local backup files are used during processing. The recovery key is intended to be kept separately from the server. Backup files and credentials are never published on this website or its public repository.

Sharing and use

Google data is used only for the backup, verification, retention and recovery functions described here. It is not sold, used for advertising, or used to train AI models. Scheduled backup processing runs deterministic scripts and does not send archive contents to an AI model. Google stores the uploaded archives; the server provider hosts the utility. The owner controls access and may access data for maintenance or recovery.

Juno Backups' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and control

The owner controls the retention settings and may delete backups through Google Drive. Removing the app's access in Google Account permissions revokes future access but does not itself delete previously uploaded files. Local credentials and backup files can also be deleted by the owner. Automatic retention is enabled only after the owner selects its policy.

This website

This static information site has no sign-in, forms, analytics scripts or advertising. GitHub Pages hosts it and may process technical request information under GitHub's privacy statement.

Contact and updates

For questions, contact the maintainer through the project issue tracker. Issues are public: do not include private files, credentials or account information. This policy will be updated if the utility's data practices change.
