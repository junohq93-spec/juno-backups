Personal backup utility

Juno Backups

A private utility being configured to protect its owner's Hermes agent data with encrypted backups stored in the owner's Google Drive.

Purpose and Google access

The utility uses Google Drive access to create backup folders, upload encrypted archives, verify uploads and manage backup retention. It is for the owner's personal use and is not offered as a public service.

Google access is limited to Drive. The utility does not request Gmail, Calendar or Contacts access. Scheduled backup processing uses scripts rather than an AI model.

This public website provides information only. It does not provide access to the backup system or store backup archives, passwords or OAuth credentials.
